# PDAC Project Workflow Summary: Agent and K-Dense Skill Usage Record

## 1. Overall Project Workflow

This project is an LLM-assisted bioinformatics workflow built around multi-omic evidence integration for PDAC. It covers data-source provenance verification, bulk / single-cell / spatial / microbiome analyses, cross-layer synthesis, target prioritization, manuscript drafting, reference auditing, submission-package assembly, and final QA.

## 5. A Reusable, Simplified Process Template

- **Phase 0: Establish project structure and git management** — initialize a standardized multi-tier directory structure and `.gitignore` configuration to keep code and data isolated.
- **Phase 1: Lock down data provenance and accession information** — verify public-database accessions and sample counts, and build an authoritative patient-level sample crosswalk.
- **Phase 2: Complete the primary analysis** — QC, filter, and transform the expression and microbiome data, then run host-subtype stability analysis and genus-subtype continuous association analysis.
- **Phase 3: Run external validation** — validate candidate features across independent bulk, single-cell (avoiding pseudoreplication), and spatial (following paired mixed-effects models and compartment isolation) datasets.
- **Phase 4: Cross-layer synthesis** — build a scoring model on top of multi-layer computational evidence, applying a composition penalty to features lacking single-cell/spatial support or showing internal inconsistency.
- **Phase 5: Target prioritisation** — integrate public target databases (e.g., OpenTargets, GTEx) to audit candidate-target feasibility and set priority ranking.
- **Phase 6: Manuscript drafting** — assemble the initial draft from the outline, and build a claim-to-text traceability table linking scientific claims to computational results.
- **Phase 7: Claim-control audit** — independently audit the manuscript text, strictly reviewing and correcting wording for key claims such as non-causal microbial associations and localized spatial findings.
- **Phase 8: Reference and callout audit** — use citation-management tooling to proofread the BibTeX reference database, and automatically verify and repair in-text citations and figure/table callouts.
- **Phase 9: Submission package assembly** — assemble the manuscript, references, figures/tables with legends, draft the cover letter, and package everything according to the target journal's checklist.
- **Phase 10: Journal-specific formatting and final QA** — compare against submission guidelines for a final formatting check and journal-specific gap audit, and output a readiness decision.
